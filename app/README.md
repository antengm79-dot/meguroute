# めぐる〜と（Webプロトタイプ）

10〜20代向けのおでかけアプリ「めぐる〜と」のプロトタイプです。
ルートの計画（AI）、記録、スポットでの撮影、Vlog、共有までを1つのアプリで行えます。
課金店舗向けの管理画面も入っています。

## 起動方法

```bash
cd app
npm install
npm run dev
```

ブラウザで表示されたURL（例：http://localhost:5173）を開きます。
PCではスマホ枠つきで表示され、スマホでは全画面で表示されます。

## デモ歩行

旅の途中の画面では、ルートに沿って自動で歩くデモが動きます（動画撮影用）。
徒歩区間は約10秒で進みます。
スポットに着くと「写真を撮りますか？」が表示されます。

## 写真の差し替え

`public/photos/` に次の名前で画像を置くと、仮の画像（色のグラデーション）と自動で置き換わります。

| ファイル名 | 内容 |
|---|---|
| `c1-1.jpg` 〜 `c1-6.jpg` | 喫茶ミナモ（みんなの写真） |
| `c1o-1.jpg` 〜 `c1o-3.jpg` | 喫茶ミナモ（お店公式の写真） |
| `c3-*.jpg` / `c3o-*.jpg` | 中崎珈琲舎 |
| `b1-*.jpg` / `b1o-*.jpg` | 古着屋 ROUTE |
| `c5-*.jpg` / `c5o-*.jpg` | 川床カフェ ナギ |
| `p1-1.jpg` 〜 `p1-6.jpg` | 中之島バラ園 |

ほかのお店のIDは `src/data/spots.ts` に書いてあります。
撮影画面の右下からは、端末の写真をそのまま旅に追加できます。

## 地図

- 地図は MapLibre GL JS と OpenFreeMap を使っています。全国対応で、APIキーは不要です。
- 地図上の店名をタップすると、店名とみんなの写真が表示されます。
- 地図が読み込めない環境では、格子模様の背景の上にルートとお店だけが表示されます。
- 徒歩ルートは routing.openstreetmap.de を使います。つながらない場合は、デモ用に用意した道筋か直線で代わりに描きます。

## 実際の地図とカメラ

- 地図は OpenStreetMap Japan（日本語ラベル）を使います。つながらない場合は OpenFreeMap に切り替えます。
- カメラは `getUserMedia` で撮影します。HTTPSのサイト（GitHub Pagesなど）か `localhost` で動きます。バックエンドは要りません。
- `.github/workflows/pages.yml` で、`main` にpushすると GitHub Pages に公開されます（リポジトリの Settings → Pages で「GitHub Actions」を選んでください）。
- claude.ai の公開ページの中では外部の地図とカメラが制限されるため、地図は格子模様の背景、撮影はプレビュー撮影になります。

## レベルの基準

写真とスポットを重視して、1回のおでかけで次のXPを獲得します。

| 記録 | XP |
|---|---|
| 写真1枚 | 12XP |
| スポット1か所 | 30XP |
| 歩いた距離 1km | 10XP |

Lv.n から Lv.n+1 には `60 + 20 × n` XPが必要です。Lv.10でゴールド、Lv.20でオーロラのフチが解放されます。

## 大阪のお店データ（osaka_spots.csv）

`src/data/osaka_spots.csv` のお店・スポットを地図に表示しています（`src/data/osakaSpots.ts` で読み込み）。
CSVを差し替えれば地図のお店も入れ替わります。列は `id,名前,カテゴリ,マップ,マップ内の位置,緯度,経度,住所` です。

- カフェ→カフェ、レストラン・ラーメン→グルメ、スイーツ・パン→スイーツ、公園→公園、海辺→海、観光スポット→神社・寺（神社・寺の名前のとき）または映え
- キャンパスと駅は、出発地・到着地の検索候補になります
- 実在のお店には営業時間・混雑・「空き」などは付けず、店名・カテゴリ・住所だけを表示します
